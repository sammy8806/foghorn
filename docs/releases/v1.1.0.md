# Foghorn v1.1.0

Foghorn 1.1.0 makes the app easier to install, easier to position, and more predictable to run day to day. This release adds packaged binaries for macOS and Linux, introduces configurable popup placement, improves tray and quit behavior, and migrates configuration into the correct platform-specific location automatically.

## Highlights

- Packaged desktop releases for both major targets:
  - macOS universal DMG builds
  - Linux x86_64 AppImage builds
- Configurable popup placement with support for all four screen corners
- Automatic migration from the legacy config path into the proper platform-specific config directory
- Improved tray behavior with clearer active vs silenced alert state and more reliable quitting
- macOS tray-only behavior now hides the Dock icon when the window is hidden

## Improvements

- Added release build scripts and a GitHub Actions workflow for shipping signed macOS DMGs and Linux AppImages
- Improved popup sizing and positioning logic across macOS and Linux
- Refined validation and config defaults for popup placement
- Better tray tooltip and icon behavior by separating active alerts from silenced alerts
- Improved application shutdown handling, including signal-driven quits from the CLI
- Updated configuration documentation and example config comments for the new config locations and UI options
- Fixed AppImage builds on newer Fedora and Ubuntu environments

## Notes

- Release artifacts:
  - `foghorn-1.1.0-universal.dmg`
  - `foghorn-1.1.0-x86_64.AppImage`
- The Linux AppImage is intentionally a thin AppImage: it bundles Foghorn but
  uses the host system's GTK/WebKitGTK runtime. This avoids cross-distro
  renderer crashes from shipping Ubuntu's WebKitGTK/GStreamer/EGL stack inside
  the AppImage.
- Linux runtime dependencies:
  - Fedora/KDE/GNOME: `sudo dnf install webkit2gtk4.1 gtk3 libayatana-appindicator-gtk3`
  - Ubuntu 24.04/Kubuntu: `sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libayatana-appindicator3-1`
- KDE is supported, but Wails still uses WebKitGTK for the embedded web view on
  Linux, so KDE users also need the GTK/WebKitGTK runtime packages.
- Existing users with a legacy config under `~/.config/foghorn/config.yaml` on macOS or Windows will be migrated automatically on startup.
